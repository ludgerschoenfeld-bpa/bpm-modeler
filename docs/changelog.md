# Changelog

All notable user-visible changes are recorded here. The project follows [Semantic Versioning](https://semver.org/).

## 1.0
- BPMN, DMN and CMMN editors
- Specific BPMN Editor Features: 
  - Copy, cut, and paste BPMN elements
  - Highlight BPMN elements with color
  - Define the process scope and save it as BPMN XML
  - Define the main activities of the top-level process and save them as BPMN XML
  - Token Simulator
- Specific CMMN Editor Features: 
  - Copy, cut, and paste CMMN elements
  - Highlight CMMN elements with colors
- Specific DMN Editor features:
  - Support: DRD + Boxed Expressions (Boxed Function, Boxed Context, List, Boxed Invocation, ...)
  - DMN test cases: definition and evaluation of test cases for decision models
  - Integrating External DMN Models
- PDF documentation & SVG export
- Best‑practice support for BPMN & DMN
- Internationalization: UI support for German and English
- Help system
