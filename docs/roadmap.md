# Roadmap: BPM Modeler
(Subject to change in future versions / Last Update: 06.09.2026)


# V 1.0
- BPMN, DMN and CMMN editors
- DMN support:
  - DRD + Boxed Expressions
  - DMN test cases: definition and evaluation of test cases for decision models
  - Integrating External DMN Models
- PDF documentation & SVG export
- Best‑practice support for BPMN & DMN
- Internationalization: full UI support for German and English


# V 2.0
- DMN enhancements:
  - Extend DMN test case support with advanced input types such as lists and contexts, as well as integrated external DMN models
  - Assistant for the methodical, step-by-step creation of a DMN decision model
- Conceptual data model definition (including export as PDF, SVG, and Markdown)
- Product backlog
  - Definition and prioritization of functional requirements (including export as Markdown)
  - Definition of non-functional requirements (including a distinction between global and requirement-specific NFRs; export as Markdown)

# V 3.0
- Product Board for planning the digital product
- Service contract documentation support (interface operations) for BPMN message flows
